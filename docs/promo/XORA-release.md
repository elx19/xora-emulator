# Material de publicación de XORA

## Mensaje corto

XORA es un emulador Android ligero para Windows. Instala APK, APKS o XAPK, abre cada aplicación en su propia ventana y ajusta el rendimiento, el mando, el teclado, el mouse y el DPI desde una interfaz sencilla.

La imagen oficial incluye Google Play Store y Servicios de Google para iniciar sesión y descargar aplicaciones. El runtime pesado no se incrusta en el instalador ligero: se descarga desde el Release oficial de GitHub, se verifica con SHA-512 y se reutiliza en los siguientes arranques.

## Texto para redes

Emula Android de forma sencilla con XORA: instala tus APK, usa Google Play, abre cada aplicación en una ventana independiente y elige un perfil para ahorrar recursos o jugar con mayor fluidez. XORA descarga los componentes desde GitHub, valida cada actualización y no depende de otro emulador instalado en el equipo.
