# Compatibilidad y alcance de XORA

XORA no depende de FydeOS, MuMu, BlueStacks, LDPlayer, WSA ni de otro emulador instalado. El backend oficial usa Android Emulator y QEMU, con un runtime descargado y validado por XORA.

Si una aplicación no inicia, usa Diagnóstico y reparación para revisar aceleración, GPU, memoria, red, ADB y compatibilidad ARM. No se recomienda mezclar el ADB o los archivos de otro emulador porque puede dejar dispositivos, puertos y snapshots en estados incompatibles.
