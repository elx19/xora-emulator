Novedades de XORA 0.6.3

- Animación de inicio más limpia y espera hasta la primera imagen de la aplicación.
- Apertura más rápida mediante detección temprana del proceso y de la ventana.
- Nuevo laboratorio para la función experimental de varias aplicaciones.
- Diagnóstico más preciso de errores de DLL, controladores y rutas de Windows.
- Actualizaciones incrementales verificadas para la versión portátil.
- La versión ligera descarga el runtime desde GitHub y conserva el sistema Android, las aplicaciones y las instantáneas.
